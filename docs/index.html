Algorithm

Write the rule as code: a function body receiving the row and returning the action. It is compiled into a table for every row up to the graph’s largest degree, so the engine and the exact game use exactly what you wrote. Rows in the table below still win over it.

Undefined rows

c t p

Rows you define below always win over the default. With “nothing”, the first undefined row the agent reads stops the play and asks you for its action, so a rule can be built while playing.

Import / export

One row paint>target per line, the engine’s rule_final.txt format; lines starting with # are ignored.

All adversarial executions

The exact game enumerates every position the adversary can reach under the rule. “Explores” means no adversarial execution leaves a vertex unvisited; “fails” comes with one trapping execution you can replay.

Quick adversary walks

Rows are own.bag: the agent’s colour, then one digit per colour counting its neighbours of that colour. Actions are paint>target. Shortcuts: N E M D S modes, → step, A auto step, Space play. Rules can be written as code in the Rules tab; everything else is computed in Rust compiled to WebAssembly, no libraries.

Graph as text

Format n start u-v,u-v,… with vertices 0…n−1. Imported vertices are laid out on a circle; drag them afterwards.
